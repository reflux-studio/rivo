# 测试用例模板

用例维护场景和预期，执行结果另记。位置遵循用户指定或公共工作约定。

```markdown
# <范围>：测试用例

依据：<需求、规则、设计和接口的来源及版本>
范围：<覆盖与排除>

## <ID> <场景>

- 依据与风险：<来源、为什么验证>
- 方式：<接口／集成／端到端／视觉交互／其他>
- 前置条件：<版本、环境、账号、数据和依赖>
- 操作：<输入与步骤>
- 预期：<可观察的输出、状态、数据及下游效果>

## 覆盖与缺口

| 需求或风险 | 用例 | 缺口及原因 |
| --- | --- | --- |
| <来源> | <ID> | <无或说明> |
```
