# 缺陷记录模板

已有缺陷系统时沿用其中的记录。正文区分观察与原因假设，后续运行保留独立证据。

```markdown
# <缺陷 ID> <现象>

- 记录负责人：<测试身份或实际负责人>
- 依据及版本：<需求、设计或规则来源>
- 待测版本与环境：<实际运行版本、入口、账号、数据>
- 前置条件与步骤：<可重复操作>
- 预期：<依据支持的可观察结果>
- 实际：<观察到的结果；复现频率及未复现的条件>
- 影响与严重程度：<受影响范围、理由>
- 证据：<日志、截图、查询结果及位置>
- 处理对象与请求：<对应负责人、期望处理>
- 后续：<回复、修复版本、复测和回归记录链接>
```
