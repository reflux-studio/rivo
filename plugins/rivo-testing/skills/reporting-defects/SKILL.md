# 报告缺陷

开始时说明正在使用 `rivo-testing:reporting-defects` 和本次范围。同一项工作中不重复声明。通过宿主发现的公共 `rivo` 技能取得入口与工作约定；公共包不可用时说明依赖缺失，不启动领域工作流。

1. **核对并复现。** 对照需求、设计或已确认规则，记录依据版本、环境、实际待测版本、数据和账号。安全且有授权时重复操作并保留原始证据；无法复现或环境受阻如实记录，不推断已修复。
2. **写清差异。** 按[缺陷模板](references/defect.md)记录步骤、预期、实际、影响、严重程度及证据。涉及敏感数据时按授权安全处理。预期冲突或缺失交需求负责人确认；不能为了匹配实现改预期。
3. **交对应负责人。** 通过宿主发现的公共 `rivo:collaborating` 技能识别工单中对应开发或产品参与方并发起请求。已授权的 Agent 通信可直接进行；真实 IM 需要独立授权。能力、接收方或可读材料不足时保留待处理与解除条件，不声称送达。协作详情放在公共协议指定的独立记录中，不写入工单正文。
4. **核对修复。** 记录回复和实际部署的新版本，交 `rivo-testing:testing` 复测原问题并按影响回归。只有具备可观察证据才能报告复测结果；保留原失败和后续记录。测试可协助定位，不修改产品代码或需求，也不替负责人接受风险。
