# 调查委派提示词

只委派能独立回答的问题，给出原始材料和已有发现，不把主代理的猜测写成结论。

```text
查清指定问题，不选定业务或技术做法，不修改他人的工作材料，不再派代理。

问题与它影响的判断：<实际内容>
原始来源、已有证据及版本：<实际内容>
尚不确定的部分或候选解释：<实际内容>
相关目录、环境和允许操作：<默认只读；允许实验时写明范围>
返回位置与格式：<当前任务约定>

使用已连接的相关工具。研究问题追到原始来源，核对时间、样本和适用条件；系统问题沿入口、调用、状态和数据追到结果。验证候选能力时检查实际行为和接入条件，不只返回搜索命中。证据冲突时回查来源和版本。

加载 rivo:writing-clearly。返回直接答案、支持它的证据、适用范围和未查明部分。区分文档声明、推断、模拟实验与真实观察；证据足够就结束，受阻时报告具体缺口和解除条件。
```

委派者核对结果，在本人负责的主题笔记中更新结论，再继续原任务。
