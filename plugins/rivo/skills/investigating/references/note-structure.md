# 调查笔记

一个主题回答一组相关问题，沿用用户或当前工作约定给定的位置。笔记保留结论的依据，读者不必重新经历排查过程。

```markdown
# <主题>

负责人：<身份>。来源与依据版本：<材料、时间或版本>。

## 调查范围
<要回答的问题、影响的判断和允许调查的范围；使用过的知识库基线>

## 调查结论

### <机制或问题>
<直接答案、适用条件及必要的因果说明；需要比较或精确定义时用表格>

> 依据：<核对过的原始材料、路径与行号、配置或运行记录>。
> 证据类型：<文档声明／推断／模拟实验／真实观察>。

## 未查明的部分
<证据还缺什么、影响哪个判断、下一项有效检查；已进入决定记录的问题引用其编号>
```

- **只写查到的事实与推断**：是否采用某种做法，由相应负责人在自己的决定或工作材料中维护
- **依据能追溯**：保留来源位置、版本、必要的命令与输出；复现需要时才保留排查经过
- **当前结论只有一处**：其他材料引用笔记，不复制一份持续维护的调查结论
- **说明边界**：仍适用于其他版本或范围的结论保留，写明适用条件
