# 探索产品问题

开始时说明正在使用 `rivo-product:discovering-products`，并用一句话说明本次要做什么。同一项工作中不重复声明。

从用户当前问题或想法开始。公共 rivo 是本技能的依赖；通过宿主发现公共 using-rivo。缺少公共包时说明依赖缺失并停止，不自动安装。材料可来自文件、链接、粘贴内容或人类同事；不可读的部分说明缺口，继续处理可用材料。

1. 明确本次要做的决定、目标用户、使用情境和约束。区分用户描述的症状、可能原因和已有解决办法。
2. 核对现有证据：谁遇到问题、何时发生、影响是什么、目前如何应对。将事实与推断、未验证假设分开，记录来源。
3. 围绕问题比较适用的方向和不采取行动的后果。说明预期收益、代价及最关键的不确定性；不要把缺失的可行性依据当作结论。
4. 找出最影响决定的假设，提出可执行的验证方式和判断依据。产品问题由产品负责人处理；技术或测试问题按公共 collaborating 与实际负责人协作。

在用户或入口工作约定的位置形成问题、方向、依据和待验证问题；标明尚待决定的事项。只请求探索时，到此结束，不强制启动后续调研或写需求。
