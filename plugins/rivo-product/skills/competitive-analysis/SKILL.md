# 竞品分析

开始时说明正在使用 `rivo-product:competitive-analysis`，并用一句话说明本次要做什么。同一项工作中不重复声明。

公共 rivo 是本技能的依赖；通过宿主发现公共 using-rivo。缺少公共包时说明依赖缺失并停止。明确分析要支持的决定、目标用户和比较范围。接受用户提供的材料或实际可用来源，不要求专用连接器。

1. 根据用户要完成的任务识别直接竞品、间接替代和现有做法；说明选取及遗漏的范围。
2. 选择与决定有关的维度，如目标用户、关键流程、能力、价格或限制。逐项记录来源和查看日期；无法确认的项目标为未知。
3. 对照同一情境分析差异及用户影响。区分厂商宣称、实际观察和用户反馈；对冲突或旧资料说明限制，不能以缺少证据断言竞品没有某能力。
4. 归纳值得借鉴、需要避开或继续核实的点，说明其依据与适用条件。竞品具备某功能本身不构成照搬的理由。

在用户或入口工作约定的位置交付比较、来源和对决策的启示。材料不可读时记录缺口并完成可验证部分；分析结束不强制进入其他阶段。
