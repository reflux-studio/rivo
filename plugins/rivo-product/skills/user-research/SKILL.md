# 用户研究

开始时说明正在使用 `rivo-product:user-research`，并用一句话说明本次要做什么。同一项工作中不重复声明。

公共 rivo 是本技能的依赖；通过宿主发现公共 using-rivo。缺少公共包时说明依赖缺失并停止。先确认研究问题和决定所需的信息。已有访谈、反馈、观察记录等可直接综合；材料可以是文件、链接、粘贴内容或人类同事提供的记录。

1. 按研究问题设计方法、目标人群与招募条件、样本范围、执行方式和记录方法。说明样本不能代表什么，遵守用户给定的隐私与授权要求。
2. 需要访谈或问卷时，编写围绕真实经历、行为和情境的开放问题及必要追问，避免诱导；把招募、实施与分析安排标为计划。
3. 综合已有材料时记录来源、日期、样本及上下文，区分观察、受访者陈述和解释。归纳主题时保留反例、矛盾与可能的群体差异；引用必须来自材料。
4. 根据证据强弱提出发现、产品含义及仍待验证的问题。不可读材料和样本不足如实说明，不编造受访者、引语、调查结果，也不把计划写成已完成研究。

在用户或入口工作约定的位置交付所需计划、提纲或综合结果。只要求其中一项时完成该项即可；涉及其他角色产物的问题通过公共 collaborating 交实际负责人。
