# 产品设计

开始时说明正在使用 `rivo-product:designing-products`，并用一句话说明本次要做什么。同一项工作中不重复声明。

公共 rivo 是本技能的依赖；通过宿主发现公共 using-rivo。缺少公共包时说明依赖缺失并停止。使用用户提供的需求、现有界面、设计链接或其他材料，确认目标任务、用户、使用环境和设计约束。链接不可读时说明缺口，可用已提供的导出或文字继续。

1. 梳理用户从入口到完成任务的流程、角色和关键分支，说明每一步的输入、结果与返回路径。
2. 定义必要的信息结构和交互：展示内容、操作、反馈、权限及不同设备或使用条件下的约束。逐项覆盖与任务相关的初始、加载、空、成功、错误、不可用及恢复状态。
3. 用当前可用的设计工具、文字或图示表达方案；需要原型时按授权和实际工具创建，标记版本与尚未确定的交互。不把假设画成已确认规则。
4. 对照现有需求和材料检查流程闭合、状态和边界，记录设计决定、依据及待确认项。技术与测试问题通过公共 collaborating 交实际负责人。

在用户或入口工作约定的位置交付流程、状态说明和需要的原型。本技能只修改产品设计产物，不编写产品代码；单独设计任务完成后结束。
