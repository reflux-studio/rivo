# 产品指标评估

开始时说明正在使用 `rivo-product:reviewing-metrics`，并用一句话说明本次要做什么。同一项工作中不重复声明。

公共 rivo 是本技能的依赖；通过宿主发现公共 using-rivo。缺少公共包时说明依赖缺失并停止。确认要判断的产品目标、时间范围与数据来源；接受用户提供的文件、链接、粘贴数据或人类资料，不要求特定分析工具。

1. 选择能回答当前问题的指标，定义统计对象、事件、分子分母、去重、时间窗口、分群与数据来源。说明基线和目标是否已确认，以及采集或数据质量缺口。
2. 有实际数据时核对口径、样本量和可比性，再比较相关时间段、目标或群体；记录数值、计算方式和来源。缺少可比数据时不判断趋势或达标。
3. 区分观察到的变化与原因假设，检查可能影响比较的事件和限制。提出值得继续调查或验证的行动，不以相关性证明因果。
4. 没有实测数据时仅交付度量方案、采集需求和待确认目标；不编造基线、目标数值或声称效果已验证。技术采集问题通过公共 collaborating 交实际负责人。

在用户或入口工作约定的位置交付指标定义、可支持的分析、限制与下一步。单独指标任务到此结束。
