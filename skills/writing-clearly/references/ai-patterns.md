# AI 腔清单

这份清单用于发现空泛、重复或不准确的表达，不能据此判断文字由谁写成。检查句子是否提供了有用信息，再决定删改；必要的对比、列举和限定应当保留。

| 类型 | 典型说法 | 改写 |
| --- | --- | --- |
| 拔高意义 | "具有重要意义""标志着……的里程碑""为……奠定坚实基础" | 删掉，或换成具体的效果："上线后超时订单不再占库存" |
| 空洞的结果短语 | "……，从而确保了系统的稳定性""进一步提升了用户体验" | 说明具体变化；有测量结果再写幅度，没有依据的效果判断删掉 |
| 宣传腔 | "强大""无缝""全面""极致""赋能" | 写它实际做什么 |
| 模糊归因 | "业界普遍认为""有观点指出" | 写出具体来源，或删掉 |
| 否定式对举 | "这不是……，而是……""不仅……更是……" | 没有实际对比作用时，直接说它是什么 |
| 凑三 | "高效、稳定、可扩展" | 逐项检查是否成立、是否有必要，不为凑齐数量添加形容词 |
| 近义词轮换 | 同一个对象一会儿叫"订单"，一会儿叫"交易单""该笔单据" | 全文用同一个名字 |
| 套话过渡 | "值得注意的是""需要指出的是""总的来说""综上所述" | 删掉，直接说内容 |
| 格式过度 | 每句加粗；解释型内容拆成"标签：说明"式的列表，因果丢在条目之间 | 加粗只留给少数关键词；解释写成段落 |
| 客套收尾 | "希望对你有帮助""如有需要可以进一步……" | 文档里删掉 |
| 过度含糊 | "在一定程度上""可能会在某些情况下" | 写出适用条件和不确定的原因，不删掉必要的限定 |
| 过满的判断 | “第一轮就会发现所有问题”“这样就能保证……” | 按已有证据限定结论，必要时说明适用条件 |
| 模板话术 | 每次开头都声明使命，结尾总是重复原则 | 说明当前任务和结果，删除没有新增信息的开场与结尾 |
| 过度比喻 | 为每个阶段安排一套比喻，再逐一解释对应关系 | 只保留能帮助理解的比喻，具体规则直接写 |
| 空泛的结尾 | "为未来的发展打下了良好基础""未来可期" | 删掉，文档在最后一条有用信息处结束 |
| 挑战与展望 | 没有具体内容的"面临的挑战""未来展望"章节 | 有待决问题就写进待决问题，没有就删 |

> 改编自 [humanizer](https://github.com/blader/humanizer)（MIT）及其依据的 Wikipedia "Signs of AI writing"，按中文写作习惯重写。
