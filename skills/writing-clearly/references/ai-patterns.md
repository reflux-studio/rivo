# AI 腔清单

下面每一类都是模型写中文时常见的习惯。逐类检查，命中的句子按"改写"一列的方向重写。

| 类型 | 典型说法 | 改写 |
| --- | --- | --- |
| 拔高意义 | "具有重要意义""标志着……的里程碑""为……奠定坚实基础" | 删掉，或换成具体的效果："上线后超时订单不再占库存" |
| 空洞的结果短语 | "……，从而确保了系统的稳定性""进一步提升了用户体验" | 说清楚确保了什么、提升了多少，说不清就删 |
| 宣传腔 | "强大""无缝""全面""极致""赋能" | 写它实际做什么 |
| 模糊归因 | "业界普遍认为""有观点指出" | 写出具体来源，或删掉 |
| 否定式对举 | "这不是……，而是……""不仅……更是……" | 直接说它是什么 |
| 凑三 | "高效、稳定、可扩展" | 只留真正成立、能举出证据的那一项 |
| 近义词轮换 | 同一个对象一会儿叫"订单"，一会儿叫"交易单""该笔单据" | 全文用同一个名字 |
| 套话过渡 | "值得注意的是""需要指出的是""总的来说""综上所述" | 删掉，直接说内容 |
| 格式过度 | 每句加粗；解释型内容拆成"标签：说明"式的列表，因果丢在条目之间 | 加粗只留给少数关键词；解释写成段落 |
| 对读者说话 | "希望对你有帮助""如有需要可以进一步……" | 文档里删掉 |
| 过度含糊 | "在一定程度上""可能会在某些情况下" | 写出在什么情况下，或确定就直接说 |
| 空泛的结尾 | "为未来的发展打下了良好基础""未来可期" | 删掉，文档在最后一条有用信息处结束 |
| 挑战与展望 | 没有具体内容的"面临的挑战""未来展望"章节 | 有待决问题就写进待决问题，没有就删 |

> 改编自 [humanizer](https://github.com/blader/humanizer)（MIT）及其依据的 Wikipedia "Signs of AI writing"，按中文写作习惯重写。
