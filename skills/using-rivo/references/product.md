# 产品工作

需要 rivo-product。先核对用户当前问题与已有材料，不强制从调研重做。可单独执行其中一项工作，完成即结束。

| 要做什么 | 领域技能 | 结束于 |
| --- | --- | --- |
| 探索目标、用户问题与假设 | discovering-products | 可判断的方向与待验证问题 |
| 调查市场及替代方式 | market-research | 有来源、口径与限制的研究 |
| 比较竞品与定位 | competitive-analysis | 面向本次决定的比较与启示 |
| 设计研究或综合用户材料 | user-research | 研究安排或有证据的发现 |
| 形成需求、目标与验收标准 | writing-prds | 用户确认或明确待确认的需求文档 |
| 设计流程、状态与交互 | designing-products | 可指导讨论与实现的产品设计 |
| 定义或核对指标 | reviewing-metrics | 指标口径、实际结果与限制 |

上述技能位于 rivo-product，按宿主实际发现的位置调用。产品只修改本人产品材料；技术可行性与实现问题交开发，质量发现由测试反馈。人类同事可以是参与方，不要求他们使用 Rivo。

## 默认产物位置

| 位置 | 用途 |
| --- | --- |
| product-decisions.md | 产品决定与待决问题 |
| prd.md | 当前需求、目标、指标与验收标准 |
| design.md | 产品流程、状态与交互设计 |
| metrics/ | 需要持续维护时的指标口径与分析 |

主文档直接位于需求根目录；调查、审阅、附件和执行证据使用[共享工作区](workspace.md)约定的共用目录。以上位置相对需求目录；外部文档与用户位置优先，只登记引用。决定、研究、需求各维护自己的内容，不互相搬运。没有开展的工作不创建文件。更新他人负责的上游需求时发协作请求；用户保留的确认点须有实际确认来源，不能因草稿写完自行标为已确认。
