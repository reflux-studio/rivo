# 脑暴

脑暴的产出是几个真正不同的候选方向和它们的取舍，不是一篇畅想。

## 1. 固定问题

- 用一句话写下要解决的问题或抓住的机会；
- 明确本次视角——产品价值、体验还是技术机制——以及不在讨论范围的内容；
- 列出已知的硬约束：预算、兼容、平台、既有规范。

## 2. 发散

- 至少给出三个彼此有实质差异的方向，不是同一方案的三种措辞；
- 允许提出违反现有惯例的方向，但标明它违反了什么；
- 每个方向用一句话说清它赌的是什么。

## 3. 收敛

- 用问题域的判断标准比较，不列泛泛的优缺点；
- 指出每个方向最可能死在哪里，以及验证生死的最便宜方法；
- 允许结论是“现在信息不足以选”，此时列出缺什么信息。

结果默认是草稿，去向遵循 `collaborating` 的自由协作规则。
