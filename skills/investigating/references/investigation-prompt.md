# 调查委派提示词

只委派可独立回答的问题，给已有发现和原始材料，不把主代理猜测写成结论。

```text
查清指定问题，不选定业务方案，不修改交付文档，不再派代理。

问题与它影响的判断：<实际内容>
已有结论、证据及版本：<实际内容>
尚不确定的部分或候选假设：<实际内容>
相关目录、环境和允许操作：<只读；允许试验则明确范围>

沿入口、调用、状态与数据追到结果。验证依赖时检查实际行为和接入条件，不只返回搜索命中。已有证据可能过时或错误，冲突时回查来源。

编写调查报告时加载 writing-clearly。返回直接答案、能支持结论的代码/配置/运行证据、适用范围和未查明部分。明确区分静态推断、模拟试验与真实运行；证据足够就结束，不能继续时报告具体缺口。
```

主代理核实结果，在对应主题的调查笔记中更新结论，再继续讨论、写作或实施。
