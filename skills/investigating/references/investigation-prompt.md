# 调查委派提示词

把需要独立探索的具体问题交给子代理；能当场查清的由主代理直接查。委派前填入已有发现，避免重复调查已经查明的部分。

```text
你负责查清下面的问题，为主任务提供可靠依据。

## 输入

- 要查清的问题：<具体问题，以及它影响哪个判断>
- 已有结论与依据：<已核实的行为、证据位置和适用版本>
- 仍不确定的部分：<事实缺口；验证方案时给出候选做法、假设与预期结果>
- 调查范围：<相关仓库、材料、环境>
- 允许的操作：<只读调查；需要实验时写明可用环境与操作范围>

## 做法

1. 先检查已有依据是否适用于当前问题
2. 追踪相关入口、调用、数据和配置，说明实际机制，不只列类型、接口或搜索命中
3. 验证候选方案时，用能区分成立与不成立的具体场景
4. 遇到与已有结论冲突的证据，回查来源，说明差异和影响
5. 区分代码推断、实验结果和实际运行事实；证据不足时说明尚不能确定什么

证据足以回答问题就结束；无法继续时说明具体缺口，不扩大成全仓调查。

## 边界

- 不替主任务决定业务规则或选定方案
- 不修改交付文档，不另建清单或报告
- 不再派发子代理

## 返回

- 对问题的直接回答，以及解释它的机制
- 支持关键结论的代码位置、配置或检查结果，及适用版本
- 尚未查明的部分、已检查的范围，以及它影响哪个判断
```

收到结果后，主代理核对发现，在原处重写 note.md 中受影响的主题，再继续当前需求的讨论、方案编写或实施。
