# 调查问题

从要做的判断出发，沿来源和实际行为查证，不把搜索结果或已有说法直接当作事实。

## 流程

1. 核对问题、允许调查的范围、当前材料与需要支持的决定。先查已有证据和版本，不扩大成无目标的遍历。
2. 使用已连接的相关工具读取原始来源。核对来源、时间、适用条件与实际行为；能区分候选解释时，做范围内的观察或实验。
3. 交叉检查冲突证据，区分原文声明、实际观察、模拟结果与推断。缺少数据时说明未知，不用估算冒充测量。
4. 根据当前请求返回结论、依据、限制和下一项有效检查。需要留档时，在用户或当前工作约定给定的位置按主题维护；原始材料与结论分别保留，不追加会话流水。
5. 发现超出本人产物权限的问题时，提供证据并通过 collaborating 交负责人处理。调查不代替做决定，也不直接改写他人材料。

已有结论不再成立时，指出依赖它的判断与可能影响。只有当前授权覆盖的验证可执行；外部副作用或访问条件不足时，只暂停相关检查。独立调查完成即交付，不自行启动其他工作流。
