# 协作请求记录

采用共享工作区给定的位置。相同请求的往返留在同一记录，问题正文不进入精简工单。

```markdown
# <请求ID>

- 发起方：<ID与角色>
- 接收方：<ID与角色>
- 时间：<带时区时间>
- 类型：<澄清/缺陷/变更建议等>
- 依据：<来源、版本与可访问位置>
- 当前处理：<待处理/已回复/待补充/已完成；由谁更新>

## 请求
<具体问题、可复现事实、影响和希望对方处理什么；预期与实际分开>

## 证据
<引用原始材料；未验证部分写清楚>

## 回复
<由回复方追加时间、身份、处理结果及本人产物版本；不替他人回复>

## 交接情况
<实际送达、来源可读与回复边界；失败/待转交/索引待登记及解除条件>
```

每方只写自己的请求、回复或交接事实。业务结论以对应负责人有效产物为准，不能通过改这份记录绕过产物权限。
