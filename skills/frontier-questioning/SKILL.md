# 前沿提问

把所有待定决策组织成一棵设计树：每个决策下面挂着依赖它的后续决策。

**前沿**是前置条件已全部敲定、现在就能问的那批问题。按轮工作：

1. 一轮问出整个前沿：每题编号，附上自己的推荐答案；
2. 答案依赖本轮未答问题的决策属于下一轮，不提前问；
3. 用户的回答会重塑设计树——敲定的决策把前沿向外推。重算前沿，进入下一轮；
4. 前沿为空即澄清完成：每个分支都被走到，没有默默假设。得到用户确认前不据此行动。

**事实自己查，决策交用户**：能从代码、配置、文档或工具查到的事实自行查证，可派独立任务且不阻塞——只有依赖该事实的问题等待，其余前沿照常问。只把真正需要用户拍板的决策放进问题。
