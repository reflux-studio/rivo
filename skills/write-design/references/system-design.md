# 技术方案模板

所有需求使用同一个主方案结构，详细设计按实际模块组织。保留以下元信息和七个主章节，按已调查的影响范围裁剪章节内细节；没有相关改动的机制无需展开，不适用处简短说明。执行职责只覆盖一个端或仓库时，仍交代其他系统的依赖与协作条件。复杂模块可以拆附属文档，主方案保持足以判断整体可行性。
