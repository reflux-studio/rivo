# 恢复工作并接续

恢复当前事实，不凭一份旧摘要接管工作。开始时说明本次要恢复的目标，已有授权与位置继续沿用。

## 流程

1. 用户给出位置时直接读取；没有时查当前项目的活动工作。只有唯一匹配才选用，多个候选交用户明确，不按最近修改时间猜。
2. 有工单时先读参与方和协作索引，确认当前身份、本人产物及相关待处理记录；再按公共 using-rivo 中的领域约定读取本人材料。只了解现状时保持只读。
3. 对照实际文档版本、文件改动、部署/执行版本及原证据。代码相关工作核对仓库与未提交改动；研究相关工作核对来源与时间；测试相关工作核对用例依据和运行条件。旧通过不证明新版本通过。
4. 核对当前负责人、工作树、已有批准和授权。别人负责或无法确认释放的工作先协调，不清理、覆盖或暂存他人改动，不从历史记录推导新权限。
5. 简短报告目标、有效依据、实际进展、缺口和可做的下一步。用户要求继续且范围无冲突时加载适用的领域技能或方法继续；需他人决定的内容发协作请求，其余工作继续。

旧材料没有工单或不符合当前目录时，沿已有来源核对，不自动迁移或为补齐格式创建文件。恢复摘要留在会话，当前状态更新在本人已有产物，不另建交接副本；主插件也不能修改其他角色的内容。
