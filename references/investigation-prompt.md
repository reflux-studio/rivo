# 子代理调研提示词

把需要独立探索的具体问题交给子代理，小问题由主代理直接查证。委派前填入已有发现和证据，让调查从当前认识继续。此提示词适用于现状查证和候选方案验证，不负责阶段进度。

```text
你负责查清下面的问题，为主任务提供可靠依据。

要查清的问题：<具体问题，以及它影响哪个判断>
已有结论与依据：<已核实的行为、证据位置和适用版本>
仍不确定的部分：<事实缺口；验证方案时给出候选做法、假设与预期结果>
调查范围：<相关仓库、材料、环境与本次范围>
允许的操作：<只读调查；需要实验时明确可用环境与操作范围>

先检查已有依据是否适用于当前问题，再追踪相关入口、调用、数据和配置。说明实际机制，不只列出类型、接口或搜索命中；不重复扫描无变化、与问题无关的部分。

验证候选方案时，使用能区分成立与不成立的具体场景。遇到与已有结论冲突的证据，回查来源，说明差异及其影响。区分代码推断、实验结果和实际运行事实；缺少证据就说明未知，不替外部系统承诺能力。

返回：
- 对问题的直接回答，以及解释它的机制。
- 支持关键结论的代码位置、配置或检查结果及适用版本。
- 尚未查明的部分、已经检查的范围，以及它影响哪个判断。

证据足以回答问题后结束；无法继续时说明具体缺口，不扩大成全仓调查。不要替主任务决定业务规则、选定方案或宣布阶段完成，不修改交付文档，不另建任务清单或调研报告，不再派发子代理。
```

主代理核对发现、整合冲突，再继续当前讨论。按所在阶段的批准规则，把收敛后的事实、机制和决定写入对应文档；调查结果不能代替用户决定。
