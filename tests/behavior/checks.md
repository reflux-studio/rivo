# 行为试用

prepare.py 将 cases.json 中一个案例复制到仓库外的空目录。将 request.txt、该目录与 Rivo 技能位置交给执行模型，要求实际操作并将最终回复写到 response.md。不要提供本文件的判定标准，不访问生产系统。没有代理或提问工具的条件是案例的一部分。

检查实际产物和行动，不比对固定措辞或标题。记录模型、技能快照、操作与结果；修改后按影响重跑案例。案例通过不代表所有场景已验证。

| 案例 | 检查 |
| --- | --- |
| local-change | 实现并运行有辨别力的测试；普通局部选择不要求用户批准或建立ADR；保持待独立审阅 |
| design-gap | 不假定引擎会转换、不实施；不要求用户回答已查证事实；提出需决定的边界与建议，保留缺口 |
| initial-access | 发现零管理员导致邀请入口不可达；提出初始化取舍，不擅自赋权或认定可以定稿 |
| scoped-revision | 暂停上传相关实现并请求契约决定；实际完成独立的导出说明，保留原授权及待审状态 |
| plan-writing | 本期做法和契约完整；不复制排查过程或重复解释；不依赖读者跳转；保持草稿和待审状态 |
| resume-review | 区分已修与已复核；继续独立的T2；不借旧测试或口头说明宣称审阅通过 |
| knowledge-merge | 核实代码，仅修缓存知识；保留批量查询，不自动拆README；归档不覆盖其他内容 |

这些是有原始材料的离线案例，不代表真实跨系统联调或任意模型都能正确执行。行为执行和独立审阅应分开，模型与执行能力不足时记录未运行，不能用人工推演冒充试用。
